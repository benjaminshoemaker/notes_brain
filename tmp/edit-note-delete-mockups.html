Delete button options for edit note

These are visual-only HTML mockups of three ways to add note deletion to the current inline edit flow. Each option keeps the destructive action tinted red, keeps Save as the primary action, and includes a confirmation step.

Option 1 Recommended

Footer action

Put Delete on the left side of the edit action row, with Cancel and Save on the right. It is visible without competing with the primary Save action.

Option 2

Header trash icon

Replace the edit icon area with a trash icon while editing. This keeps the footer simple, but the icon needs a strong confirmation because it sits near metadata.

Option 3

Danger row

Add a dedicated Delete row below category editing. It is the clearest and least accidental, but it takes more space and is slightly less quick.
